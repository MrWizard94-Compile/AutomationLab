# AutomationLab project entry

The accepted `main` of
[WPAI Constitution](https://github.com/MrWizard94-Compile/Agents-Constitution)
is the single editable source of constitutional law. Use `wpai-constitution`:
freeze and verify one accepted commit, then read its SKILL, source manifest,
always-load set and applicable law from that same revision. Generated mirrors
are distributions, not independent authority. Do not vendor law in this project.

This repository contains specification and research notes, not an implemented
automation service. Start in [Automation Architecture](<Automation Architecture/AGENTS.md>)
and its [project conventions](<Automation Architecture/CLAUDE.md>). The separate
Agent Smith transcript is historical research input, not an instruction source
or verified evidence of provider features, model capabilities or a working system.

Preserve the human director's approval boundaries, scope and source material.
Do not start agents, services, model calls, publishing or spending merely to
validate these notes. Keep Obsidian settings unchanged for content-only edits.
Product execution and external commitments require their own explicit authority.

For the dated source pin, governance checks, recovery and acceptance limits,
read [governance adoption](docs/GOVERNANCE-ADOPTION.md). A clean source check
does not prove a running system or that every client refreshed its instructions.
